# Changelog

## 3.0.0

- Add a worksheet Viz Extension with three hierarchy Marks-card encodings and native Tableau selection.
- Port Hierarchy Navigator / Filter as a standalone Viz Extension.
- Replace the external tree-menu dependency with an owned visible-row projection.
- Add a modern navigator shell, responsive styling, English/German setup, and portable navigator settings.
- Add event-driven refresh, native selection synchronization, stale-response protection and serialized output.
- Keep dashboard manifests and configuration as explicit compatibility artifacts.
- Add model/lifecycle tests and a local Tableau API browser fixture.
